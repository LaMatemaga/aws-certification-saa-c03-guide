# AWS Well-Architected Tool

The AWS Well-Architected Tool is a service that helps you review the state of your workloads and compares them to the latest AWS architectural best practices. It provides a consistent process for measuring your architecture against best practices and identifying areas for improvement.

## Key Features

- **Workload reviews**: Assess workloads against the Well-Architected Framework.
- **Best practice guidance**: Access AWS best practices for cloud architectures.
- **Improvement plans**: Create plans to address identified issues.
- **Milestone tracking**: Track progress against improvement plans.
- **Custom lenses**: Create custom frameworks for specific requirements.
- **Shared lenses**: Share custom lenses across accounts.
- **Lens catalog**: Access AWS and partner-created lenses.
- **Dashboard views**: Visualize workload status and improvements.
- **Report generation**: Create and download review reports.
- **Workload sharing**: Share workloads with other AWS accounts.
- **Multi-account support**: Review workloads across AWS accounts.
- **Integration with AWS services**: Connect with Trusted Advisor and other services.
- **Service blueprint integration**: Use service-specific recommendations.
- **Template-based workloads**: Create workloads from templates.

## Well-Architected Framework Pillars

- **Operational Excellence**: Running and monitoring systems to deliver business value.
- **Security**: Protecting information, systems, and assets.
- **Reliability**: Ensuring a workload performs its intended function correctly and consistently.
- **Performance Efficiency**: Using computing resources efficiently to meet requirements.
- **Cost Optimization**: Avoiding unnecessary costs.
- **Sustainability**: Minimizing the environmental impacts of running cloud workloads.

## Lenses Available

- **AWS Well-Architected Framework**: Core best practices for cloud workloads.
- **Serverless Application Lens**: Best practices for serverless applications.
- **Containers Lens**: Best practices for containerized workloads.
- **SaaS Lens**: Best practices for Software as a Service providers.
- **Machine Learning Lens**: Best practices for machine learning workloads.
- **Data Analytics Lens**: Best practices for analytics workloads.
- **IoT Lens**: Best practices for Internet of Things applications.
- **HPC Lens**: Best practices for high-performance computing.
- **Games Industry Lens**: Best practices for game development and hosting.
- **Financial Services Industry Lens**: Best practices for financial services.
- **Healthcare Industry Lens**: Best practices for healthcare workloads.
- **Custom lenses**: Create your own specialized lenses.

## Review Process

- **Workload definition**: Define your workload and its boundaries.
- **Question responses**: Answer questions about your architectural decisions.
- **Risk identification**: Identify high, medium, and low risk items.
- **Improvement plan**: Create a plan to address identified risks.
- **Milestone creation**: Set milestones to track progress.
- **Re-review**: Periodically reassess workloads.
- **Best practice integration**: Implement recommended best practices.
- **Report sharing**: Share review results with stakeholders.
- **Continuous improvement**: Iterate on architectural improvements.

## Pricing

The AWS Well-Architected Tool is available at no additional charge. You can use it to review as many workloads as you want across your AWS accounts. There are no fees for creating workloads, conducting reviews, or implementing improvement plans. You only pay for the AWS resources you create as part of implementing your improvement plans.
