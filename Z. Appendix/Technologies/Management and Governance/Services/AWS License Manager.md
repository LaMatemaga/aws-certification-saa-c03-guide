AWS License Manager simplifies the management of software licenses across AWS and on-premises environments. It helps you control and optimize licensing costs, enforce license usage rules, and improve compliance with licensing terms.

## Key Features

- **License rule creation**: Define licensing rules based on vendor terms.
- **Self-managed licenses**: Track and manage your existing licenses.
- **License usage tracking**: Monitor usage of licenses across your environment.
- **Hard and soft limit enforcement**: Set and enforce licensing limits.
- **License aggregation**: Pool licenses across multiple accounts.
- **License type conversion**: Convert license types (e.g., BYOL to subscription).
- **Automated discovery**: Find licensable resources in your environment.
- **Cross-account inventory**: View license inventory across AWS Organizations.
- **Resource inventory tracking**: Track the association between licenses and resources.
- **Host resource group management**: Manage dedicated host resources collectively.
- **Automated host allocation**: Automatically place instances on appropriate hosts.
- **License reporting**: Generate reports on license usage and compliance.
- **License sharing**: Share licenses across accounts within your organization.
- **Integrated with AWS Marketplace**: Manage AWS Marketplace licenses.
- **Linux subscriptions**: Track and manage Linux subscriptions.

## License Types Supported

- **Self-managed licenses**: Licenses you've purchased directly from software vendors.
- **AWS Marketplace licenses**: Licenses acquired through AWS Marketplace.
- **Seller issued licenses**: Licenses issued by AWS Marketplace sellers.
- **Subscription-based licenses**: Licenses based on recurring subscriptions.
- **User-based licenses**: Licenses based on the number of users.
- **Socket-based licenses**: Licenses based on CPU sockets.
- **Core-based licenses**: Licenses based on CPU cores.
- **Instance-based licenses**: Licenses based on the number of instances.
- **Virtual machine-based licenses**: Licenses tied to virtual machines.
- **Linux subscriptions**: RHEL, SUSE, and Ubuntu Pro subscriptions.

## License Rules

- **License count limits**: Maximum number of licenses allowed.
- **License count hard limits**: Strictly enforced license limits.
- **License count soft limits**: Warning-only license limits.
- **License affinity to host**: License tied to a specific host.
- **License affinity to physical core**: License tied to physical CPU cores.
- **License affinity to socket**: License tied to CPU sockets.
- **License affinity to VM**: License tied to virtual machines.
- **License tenancy requirements**: Specific instance tenancy requirements.
- **License usage operation controls**: Control license-impacting operations.

- **License compliance enforcement**: Ensure compliance with licensing terms.
- **Centralized license management**: Manage licenses across multiple accounts.
- **Dedicated Host management**: Optimize the use of EC2 Dedicated Hosts.
- **BYOL management**: Track and manage Bring Your Own License resources.
- **License usage reporting**: Generate reports for compliance and auditing.
- **Automated license enforcement**: Prevent usage beyond licensed limits.

## Integration with AWS Services

- **AWS Organizations**: Manage licenses across your organization.
- **AWS Resource Groups**: Group resources for license management.
- **AWS Systems Manager**: Inventory and manage on-premises resources.
- **Amazon EC2**: Manage licenses for EC2 instances.
- **Amazon RDS**: Track database engine licenses.
- **AWS CloudFormation**: Provision license configurations as code.
- **AWS CloudTrail**: Audit license management activities.
- **AWS Marketplace**: Manage AWS Marketplace licenses.
- **AWS Service Catalog**: Include license rules in provisioned products.
- **AWS IAM**: Control access to license management functions.
