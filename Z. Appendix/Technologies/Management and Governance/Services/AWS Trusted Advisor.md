# AWS Trusted Advisor

AWS Trusted Advisor is an online tool that provides real-time guidance to help you provision your resources following AWS best practices. It examines your AWS environment and makes recommendations for improving security, saving money, optimizing performance, improving resilience, and closing feature gaps.

## Key Features

- **Best practice checks**: Automated evaluation of your AWS environment against best practices.
- **Real-time guidance**: Up-to-date recommendations based on current resource state.
- **Multiple categories**: Recommendations across cost, performance, security, fault tolerance, and service limits.
- **Priority levels**: Issues flagged as critical, warning, or ok based on severity.
- **Action links**: Direct links to make recommended changes.
- **Check history**: Track improvement progress over time.
- **Weekly notifications**: Email summaries of Trusted Advisor results.
- **Programmatic access**: API and SDK access to Trusted Advisor data.
- **Organizational view**: View results across AWS Organizations.
- **Excluded resources**: Exclude specific resources from checks.
- **Check refresh**: Refresh check results on demand.
- **Integration with other AWS services**: Connect with CloudWatch, EventBridge, and more.
- **Custom checks**: Define custom checks via AWS Config (Business and Enterprise Support).
- **Proactive recommendations**: Suggestions to help you follow AWS Well-Architected best practices.

## Check Categories

- **Cost Optimization**: Recommendations to save money by eliminating unused and idle resources or making commitments to reserved capacity.
- **Performance**: Recommendations to improve the performance and responsiveness of your services.
- **Security**: Recommendations to improve the security of your AWS environment by closing gaps, enabling various AWS security features, and examining your permissions.
- **Fault Tolerance**: Recommendations to help improve the resiliency of your AWS solutions by implementing redundancy, fault tolerance, and recovery capabilities.
- **Service Limits**: Recommendations to ensure you're not approaching service quotas (formerly called "limits") for your AWS resources.
- **Operational Excellence**: Recommendations that help you operate your workloads more effectively.
- **Sustainability**: Recommendations to help you align your workloads with sustainability best practices.

## Access Levels

- **Basic Support**: Limited access to cost optimization and security checks.
- **Developer Support**: Basic checks plus a limited number of performance and fault tolerance checks.
- **Business Support**: Full access to all Trusted Advisor checks and features.
- **Enterprise Support**: Full access plus AWS Support API and prioritized check development.

## Common Use Cases

- **Cost reduction**: Identify opportunities to reduce AWS spending.
- **Security enhancement**: Find and address security vulnerabilities.
- **Performance improvement**: Optimize resource configuration for better performance.
- **Disaster recovery planning**: Enhance fault tolerance and resilience.
- **Service limit management**: Proactively manage service quotas.
- **Architecture validation**: Validate architecture against AWS best practices.
- **Compliance assessment**: Check security configurations against best practices.
- **Resource optimization**: Right-size and optimize your resources.
- **Operational risk reduction**: Identify potential operational issues.
- **Best practice implementation**: Ensure AWS resources follow recommended practices.

## Integration with AWS Services

- **AWS Organizations**: View Trusted Advisor results across organizational accounts.
- **Amazon CloudWatch**: Create alarms based on Trusted Advisor metrics.
- **Amazon EventBridge**: Trigger automated actions based on Trusted Advisor results.
- **AWS Config**: Create custom Trusted Advisor checks.
- **AWS Security Hub**: Correlate Trusted Advisor security findings.
- **AWS Compute Optimizer**: Complement optimization recommendations.
- **AWS Cost Explorer**: Detailed analysis of cost optimization opportunities.
- **AWS Support API**: Programmatic access to Trusted Advisor data.
- **AWS Well-Architected Tool**: Align with Well-Architected Framework best practices.

## Pricing

AWS Trusted Advisor is included with your AWS Support plan:
- **Basic Support**: Limited checks at no additional cost.
- **Developer Support**: Additional checks included with Developer Support plan.
- **Business Support**: Full access included with Business Support plan.
- **Enterprise Support**: Full access with additional features included with Enterprise Support plan.

The specific cost depends on your AWS Support plan, which is typically based on a percentage of your AWS usage with a minimum monthly fee.
