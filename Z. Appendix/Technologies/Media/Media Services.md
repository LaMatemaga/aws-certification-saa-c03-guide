- [[Amazon Elastic Transcoder]] - A scalable media transcoding service that converts media files from their source format into versions optimized for various playback devices. The document includes information about supported formats, system architecture, common use cases, and a note that while still supported, AWS now recommends [[AWS Elemental MediaConvert]] for new workflows.
- [[Amazon Kinesis Video Streams]] - A fully managed service for securely streaming video from connected devices to AWS for analytics, machine learning, and playback. The document covers stream types, supported protocols, architecture components, and integration with AWS services like [[Amazon Rekognition]] for video analysis.
