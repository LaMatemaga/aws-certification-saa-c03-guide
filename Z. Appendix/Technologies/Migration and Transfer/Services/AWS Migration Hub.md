AWS Migration Hub provides a single location to track the progress of application migrations across multiple AWS and partner solutions. It offers visibility into your application portfolio and streamlines the planning and tracking of your migration projects, regardless of which migration tools you use.

## Key Features

- **Centralized migration tracking**: Track migrations across multiple tools from a single dashboard.
- **Application discovery**: Discover on-premises servers and applications using Application Discovery Service.
- **Application grouping**: Organize servers into applications for migration planning.
- **Migration status visualization**: Visual representation of migration progress.
- **Multiple migration tool integration**: Works with both AWS and partner migration tools.
- **Migration strategy planning**: Assess applications and plan migration strategies.
- **Status updates automation**: Automatic tracking of migration status.
- **CloudWatch integration**: Monitor migration metrics and set up alarms.
- **Multi-account support**: Track migrations across multiple AWS accounts.
- **API access**: Programmatically access migration data and status.
- **Region selection flexibility**: Select the AWS region where your migration metadata is stored.
- **Secure migration tracking**: Encrypted data storage and IAM integration.

## Integrated Migration Tools

### AWS Tools

- **AWS Application Discovery Service**: Discover on-premises applications and dependencies.
- **AWS Application Migration Service**: Automate lift-and-shift migrations.
- **AWS Database Migration Service**: Migrate databases to AWS.
- **AWS Server Migration Service**: Migrate virtual machines to AWS.
- **AWS DataSync**: Transfer file data to AWS storage services.

### Partner Tools

- **Migration solutions from AWS Partners**: Integration with various third-party migration tools.
- **Marketplace migration tools**: Compatible with various AWS Marketplace solutions.

## Migration Phases Supported

- **Discover**: Find applications and servers in your environment.
- **Assess**: Evaluate applications for migration readiness.
- **Mobilize**: Prepare applications and environment for migration.
- **Migrate**: Execute the actual migration of applications.
- **Modernize**: Update and optimize applications after migration.

## Common Use Cases

- **Enterprise migrations**: Coordinate large-scale migrations across multiple teams.
- **Migration project management**: Track and report on migration progress.
- **Application portfolio assessment**: Evaluate and prioritize applications for migration.
- **Multi-tool migration coordination**: Orchestrate migrations using various tools.
- **Migration status reporting**: Generate reports for stakeholders on migration progress.
- **Resource planning**: Allocate resources based on migration status.
- **Migration standardization**: Implement consistent migration processes across projects.
- **Migration governance**: Ensure migrations follow organizational standards.

## Integration with AWS Services

- **AWS Application Discovery Service**: Discover servers and applications.
- **AWS Application Migration Service**: Automated server migrations.
- **AWS Database Migration Service**: Database migrations.
- **AWS Server Migration Service**: Virtual machine migrations.
- **AWS Control Tower**: Integration with multi-account environments.
- **AWS Organizations**: Manage migrations across organizational accounts.
- **Amazon CloudWatch**: Monitor migration activities.
- **AWS CloudTrail**: Audit Migration Hub API calls.

## Pricing

AWS Migration Hub pricing is based on:

- **Migration Hub**: No additional charge for tracking migrations.
- **Application Discovery Service**: No charge for the discovery service itself.
- **Data storage**: Standard charges apply for storing discovery data.
- **Migration tools**: Standard pricing applies for AWS migration services you use.

The Migration Hub service itself is free to use, making it a cost-effective way to track and manage your migration projects.
