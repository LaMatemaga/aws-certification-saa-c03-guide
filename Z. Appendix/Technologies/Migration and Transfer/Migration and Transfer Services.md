- [[AWS Application Discovery Service]] - Helps you discover on-premises applications and plan migrations
- [[AWS Application Migration Service]] - A highly automated lift-and-shift solution for server migration
- [[AWS Database Migration Service (AWS DMS)]] - Migrates databases to AWS with minimal downtime
- [[AWS DataSync]] - Automates and accelerates data transfers between on-premises and AWS
- [[AWS Migration Hub]] - Provides a single location to track migration progress across multiple tools
- [[AWS Snow Family]] - Physical devices for large-scale data transfer and edge computing
- [[AWS Transfer Family]] - Secure file transfer service supporting SFTP, FTPS, FTP, and AS2 protocols
