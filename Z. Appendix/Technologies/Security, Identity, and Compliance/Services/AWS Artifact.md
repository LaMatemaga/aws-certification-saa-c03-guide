AWS Artifact is a self-service portal that provides on-demand access to AWS security and compliance reports and select online agreements. It is your central resource for compliance-related information that matters to you.

## Key Features

- **Compliance reports access**: Download AWS security and compliance documents, including SOC reports, PCI reports, and certifications from accreditation bodies.
- **Self-service agreements**: Review, accept, and manage agreements with AWS for your accounts.
- **Agreement management**: Track the status of agreements across your organization's accounts.
- **Automated verification**: Provide your auditors with required AWS compliance documentation.
- **Organization management**: Accept agreements on behalf of all accounts in your AWS Organizations.

## Available Documentation Types

- ISO certifications (ISO 9001, ISO 27001, ISO 27017, ISO 27018)
- SOC reports (SOC 1, SOC 2, SOC 3)
- PCI DSS compliance reports
- FedRAMP documentation
- HIPAA compliance information
- Many regional and industry-specific compliance frameworks

## Common Use Cases

- **Regulatory compliance**: Access documentation needed to verify AWS compliance with regulatory requirements.
- **Audit support**: Provide auditors with required AWS security and compliance documentation.
- **Risk assessments**: Obtain information needed for risk assessments of AWS services.
- **Due diligence**: Perform due diligence when moving workloads to AWS.
- **Agreement management**: Efficiently manage legal agreements with AWS.

## Benefits

- **Immediate access**: Get on-demand access to compliance documentation without contacting AWS support.
- **Central repository**: Access all AWS compliance documentation from a single location.
- **Simplified compliance**: Streamline compliance verification with easy document access.
- **Reduced administrative overhead**: Manage agreements efficiently across your organization.

## Pricing

AWS Artifact is provided at no additional charge to all AWS customers.
