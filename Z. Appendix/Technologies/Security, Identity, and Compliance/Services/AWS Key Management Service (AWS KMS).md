AWS Key Management Service (KMS) is a managed service that makes it easy for you to create and control the cryptographic keys used to protect your data. AWS KMS integrates with most AWS services that encrypt your data, centralizing key management while helping you meet your compliance requirements.

## Key Features

- **Centralized key management**: Create, import, and manage cryptographic keys from a central service.
- **Key types**: Support for symmetric and asymmetric keys for encryption, signing, and authentication.
- **Custom key store**: Use AWS CloudHSM as a dedicated key store for your KMS keys.
- **Multi-tenant HSM**: Keys are protected by FIPS 140-2 validated hardware security modules.
- **Key rotation**: Automatic or on-demand rotation of KMS keys.
- **IAM integration**: Fine-grained access control with IAM policies.
- **Resource policies**: Control access to keys with key policies.
- **Multi-Region keys**: Create keys that can be used across multiple AWS regions.
- **API access**: Programmatic access to encryption operations.
- **Monitoring and audit**: Integration with AWS CloudTrail for logging all API requests.
- **Compliance**: Help meet compliance requirements for key management.

## Key Types

- **Customer managed keys**: Keys you create, own, and manage.
- **AWS managed keys**: Keys AWS creates and manages for use with specific AWS services.
- **AWS owned keys**: Keys AWS owns and manages for multiple customers.
- **Symmetric encryption keys (AES-256-GCM)**: Single key for encryption and decryption.
- **Asymmetric keys (RSA or ECC)**: Key pairs for encryption/decryption or signing/verification.
- **HMAC keys**: Keys for generating and verifying hash-based message authentication codes.
- **Data keys**: Encryption keys that KMS generates but you use outside of KMS.

## Key Origin Options

- **KMS generated**: Keys generated by AWS KMS within HSMs.
- **External**: Keys imported from your own key management infrastructure.
- **Custom key store**: Keys generated in your CloudHSM cluster.

## Common Use Cases

- **Data encryption**: Encrypt sensitive data at rest.
- **Digital signatures**: Sign and verify messages and documents.
- **Envelope encryption**: Protect data keys with master keys.
- **Secure key storage**: Store and manage keys securely.
- **Cryptographic operations**: Perform encryption, decryption, signing, and verification.
- **Compliance requirements**: Meet regulatory requirements for key management.
- **Cross-account key sharing**: Share keys securely across AWS accounts.
- **Multi-region applications**: Use multi-region keys for global applications.

## Benefits

- **Security**: Keys secured by FIPS 140-2 validated HSMs.
- **Durability**: High availability and durability for your cryptographic keys.
- **Centralized management**: Manage all keys from a single service.
- **Integration**: Seamless integration with AWS services.
- **Auditing**: Comprehensive logging of all key usage.
- **Scalability**: Scale your key usage without managing infrastructure.
- **Compliance**: Help meet compliance requirements for key management.

## Pricing

AWS KMS pricing is based on:

- Number of customer managed keys stored
- Number of API requests to KMS
- Use of custom key stores or asymmetric keys

AWS managed keys are provided at no additional charge when used with AWS services. There are no upfront costs, and you pay only for what you use.
