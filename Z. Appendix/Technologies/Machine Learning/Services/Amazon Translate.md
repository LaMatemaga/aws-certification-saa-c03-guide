Amazon Translate is a neural machine translation service that delivers fast, high-quality, affordable, and customizable language translation. It uses deep learning models to provide natural-sounding translations, allowing you to localize content such as websites and applications for international users, and to easily translate large volumes of text for analysis.

## Key Features

- **Neural machine translation**: Deep learning models for accurate translations.
- **Real-time translation**: Translate text in real-time via API calls.
- **Batch translation**: Process large volumes of text efficiently.
- **Custom terminology**: Define specific translations for domain-specific terms.
- **Active Custom Translation**: Create custom translation models for your domain.
- **Language auto-detection**: Automatically identify source language.
- **Formality settings**: Control the formality level of translations.
- **Profanity filtering**: Option to mask profane words and phrases.
- **Parallel data query**: Search for specific words or phrases in translation memory.
- **Document translation**: Translate documents while preserving formatting.
- **Multi-directional translation**: Translate between multiple language pairs.
- **Bidirectional Unicode support**: Support for right-to-left languages.
- **Parallel data analysis**: Analyze parallel text corpuses.
- **Word alignment**: View how source words align to target translations.

## Translation Methods

- **Real-time translation**: Translate text on-demand via API calls.
- **Batch translation**: Submit large documents or text collections for processing.
- **Asynchronous translation**: Process translations in the background.
- **Custom model translation**: Use domain-specific translation models.
- **Document translation**: Translate entire documents with preserved formatting.
- **Streaming translation**: Translate text as it's being generated.
- **Console interface**: Manual submission through AWS Console.
- **Regional endpoints**: Use regional endpoints for reduced latency.

## Pricing

Amazon Translate pricing is based on:

- **Character volume**: Pay per million characters of text translated.
- **Custom features**: Additional charges for custom terminology, custom translation, etc.
- **Document translation**: Special pricing for document translation features.
- **Active Custom Translation**: Charges for custom model training and usage.

Specific rates vary by region. A free tier is available for new users that includes a certain number of characters each month.
