Amazon Transcribe is an automatic speech recognition (ASR) service that makes it easy to convert audio to text. It uses advanced machine learning models to deliver accurate transcription and continuously improves over time. Transcribe can be used to transcribe customer service calls, automate closed captioning, create searchable archives, and generate meeting notes.

## Key Features

- **Automatic speech recognition**: Convert audio to text accurately.
- **Speaker identification**: Identify and label different speakers in a conversation.
- **Custom vocabulary**: Add specialized terms for your domain.
- **Language identification**: Automatically identify spoken languages.
- **Custom language models**: Create domain-specific language models.
- **Vocabulary filtering**: Filter specific words from transcriptions.
- **Content redaction**: Automatically redact personally identifiable information.
- **Batch transcription**: Process pre-recorded audio files.
- **Real-time transcription**: Transcribe streaming audio in real-time.
- **Multi-channel audio**: Process each audio channel separately.
- **Time stamps**: Include time markers for each word.
- **Confidence scores**: Receive confidence level for transcribed words.
- **Alternative transcriptions**: View alternative interpretations of audio.
- **Automatic punctuation**: Add appropriate punctuation to transcripts.
- **Numbers formatting**: Format numbers, currency, and dates appropriately.
- **Call analytics**: Extract insights from customer service calls.

- **MP4**: MPEG-4 with AAC or MP3 audio

- **OGG**: Ogg Vorbis

## Processing Methods

- **Batch processing**: Submit audio files for processing.
- **Streaming**: Real-time processing of audio streams.
- **API integration**: Programmatic access through API calls.
- **Console interface**: Manual submission through AWS Console.
- **Job submission**: Submit multiple files as a single job.
- **Async processing**: Process files in the background.

- **Medical transcription**: Specialized processing for healthcare.

## Pricing

Amazon Transcribe pricing is based on:

- **Audio duration**: Pay per second of audio processed.
- **Feature usage**: Additional charges for features like speaker identification, custom language models, etc.
- **Processing type**: Different rates for batch vs. streaming transcription.
- **Specialized services**: Different rates for medical transcription and call analytics.

Specific rates vary by region. A free tier is available for new users that includes a certain number of minutes each month.
