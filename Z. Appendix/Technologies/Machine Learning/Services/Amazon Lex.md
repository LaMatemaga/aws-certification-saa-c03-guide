Amazon Lex is a fully managed artificial intelligence service that allows developers to build conversational interfaces for applications using voice and text. It provides the advanced deep learning functionalities of automatic speech recognition (ASR) for converting speech to text, and natural language understanding (NLU) to recognize the intent of the text, enabling you to build applications with highly engaging user experiences and lifelike conversational interactions.

## Key Features

- **Speech recognition**: Convert spoken input to text with high accuracy.
- **Natural language understanding**: Determine user intent and extract data from conversations.
- **Bot building**: Create conversational agents using a visual designer or APIs.
- **Multi-turn conversations**: Support complex, multi-step interactions.
- **Built-in slot types**: Pre-built entities for common data types (dates, numbers, etc.).
- **Custom slot types**: Define domain-specific entities.
- **Lambda integration**: Process business logic seamlessly.
- **Sessions management**: Maintain context throughout conversations.
- **Automatic dialogue management**: Handle conversation flow dynamically.
- **Fulfillment logic**: Execute actions based on user intents.
- **Response cards**: Rich, visual responses with buttons and images.
- **Sentiment analysis**: Detect user sentiment during interactions.
- **Conversation logs**: Review and analyze bot conversations.
- **Versioning**: Track and manage bot versions.
- **Aliases**: Point to specific bot versions for deployment.
- **Multi-language support**: Build bots in multiple languages.

## Conversational Components

- **Bots**: The conversational interface you create.
- **Intents**: The actions that users want to perform.
- **Sample utterances**: Example phrases that invoke intents.
- **Slots**: Parameters needed to fulfill intents.
- **Slot types**: Definitions of slot data types.
- **Dialog steps**: Conversation flow for gathering information.
- **Fulfillment**: Process of completing the user's request.
- **Responses**: Bot replies to user inputs.
- **Context**: Maintaining state between conversation turns.
- **Prompts**: Questions to elicit specific information.

## Pricing

Amazon Lex pricing is based on:

- **Text requests**: Pay per text request to the service.
- **Speech requests**: Pay per speech request (voice input).
- **Speech response**: Pay per voice response generated.

Specific rates vary by region. A free tier is available for new users that includes a certain number of text and speech requests each month.
