>[!Example] **AWS Backup**
>AWS Backup is a fully managed service that makes it easy to centralize and automate data backup across AWS services. It provides a cost-effective, fully managed, policy-based solution for backing up application data across AWS services in the cloud as well as on-premises using the AWS Storage Gateway.

## Key Features

- **Centralized backup management**: Consolidate backup policies for multiple AWS services including [[Amazon Elastic Block Store (Amazon EBS)]], [[Amazon RDS]], [[Amazon DynamoDB]], [[Amazon Elastic File System (Amazon EFS)]], and [[AWS Storage Gateway]].
- **Policy-based backup solution**: Define backup schedules, retention periods, and lifecycle policies through a simple policy-based approach.
- **Cross-region backup**: Copy backups to different AWS regions for disaster recovery compliance.
- **Cross-account backup**: Manage and restore backups across multiple AWS accounts.
- **Backup compliance frameworks**: Audit capabilities to verify backup compliance.
- **Secure backups**: Data is encrypted in transit and at rest.

## Common Use Cases

- **Simplified backup management**: Centralize backup management across AWS services.
- **Regulatory compliance**: Meet backup compliance requirements with audit capabilities.
- **Disaster recovery preparation**: Create cross-region backups for disaster recovery scenarios.
- **Secure data protection**: Ensure that sensitive data is properly backed up and encrypted.

## Pricing

AWS Backup pricing is based on the amount of backup storage used, data transferred, and restore requests made. There are no minimum fees or upfront commitments.
