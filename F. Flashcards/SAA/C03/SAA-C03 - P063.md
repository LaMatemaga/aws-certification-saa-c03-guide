#Q
*A company wants to design a resilient architecture for its web application running on AWS. The application consists of multiple EC2 instances behind an Application Load Balancer (ALB) and an Amazon RDS database. Which AWS service can be used to automatically distribute incoming traffic across multiple Availability Zones (AZs) and provide high availability for the application?*
1. Amazon Route 53
2. AWS Elastic Beanstalk
3. Amazon CloudFront
4. AWS Auto Scaling
?
**Answer:**
[[Amazon Route 53]]

**Explanation:**
Amazon Route 53 is a scalable and highly available domain name system (DNS) web service. It can be used to route incoming traffic to the Application Load Balancer (ALB) across multiple Availability Zones (AZs), ensuring high availability for the web application. By leveraging Route 53's DNS-based traffic routing capabilities, traffic can be automatically distributed to healthy instances in different AZs, providing resilience and fault tolerance.
