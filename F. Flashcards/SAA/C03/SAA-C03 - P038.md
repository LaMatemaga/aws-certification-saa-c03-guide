#Q
*As an AWS Solution Architect, you are configuring the infrastructure for a web application. Currently, there is an Application Load Balancer directing traffic from developers to an EC2 instance. To prepare for public usage, you decide to introduce an Auto Scaling group and a second Application Load Balancer for routing customer traffic. Which architectural concept does this addition exemplify?*
1. Durability
2. Scalability
3. Reliability
4. Elasticity
?
**Answer:**
[[Scalability]]

**Explanation:**
By adding an Auto Scaling group and a second Application Load Balancer to route customer traffic, the system is designed to handle increasing traffic demands dynamically. This scalability feature allows for the seamless expansion of resources to accommodate higher usage levels, ensuring efficient management of user traffic during peak periods.
