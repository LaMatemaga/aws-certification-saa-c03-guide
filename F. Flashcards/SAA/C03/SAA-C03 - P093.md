#Q
*As a Solution architectural scenario you are designing a secure and resilient infrastructure on AWS, which service would you recommend for mitigating Distributed Denial of Service (DDoS) attacks and ensuring protection for your applications?*
1. AWS WAF
2. AWS Shield
3. AWS Inspector
4. DynamoDB
?
**Answer:**
[[AWS Shield]]

**Explanation:**
To provide Distributed Denial of Service (DDoS) protection to your applications running on AWS, the recommended service is AWS Shield. AWS Shield is a managed DDoS protection service that safeguards applications running on AWS against volumetric, state-exhaustion, and application layer attacks. It provides automatic protection and mitigates DDoS attacks, allowing your applications to remain available and accessible to legitimate users. AWS Shield Standard is available to all AWS customers at no additional cost and provides basic protection, while AWS Shield Advanced offers enhanced protection and additional features for more complex and sophisticated DDoS attacks.
