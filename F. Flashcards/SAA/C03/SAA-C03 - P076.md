#Q
*A financial services company has recently migrated from on-premises infrastructure to AWS Cloud. The DevOps team wants to implement a solution that allows all resource configurations to be reviewed and make sure that they meet compliance guidelines. Also, the solution should be able to offer the capability to look into the resource configuration history across the application stack. As a solutions architect, which of the following solutions would you recommend to the team?*
1. Use AWS Cloud Trail to review resource configurations to meet compliance guidelines and maintain a history of resource configuration changes
2. Use AWS Config to review resource configurations to meet compliance guidelines and maintain a history of resource configuration changes
3. Use AWS Systems Manager to review resource configurations to meet compliance guidelines and maintain a history of resource configuration changes
4. Use Amazon CloudWatch to review resource configurations to meet compliance guidelines and maintain a history of resource configuration changes
?
**Answer:**
Use [[AWS Config]] to review resource configurations to meet compliance guidelines and maintain a history of resource configuration changes

**Explanation:**
AWS Config is a service that provides a detailed view of resource configurations and enables the review of compliance guidelines. It also maintains a history of resource configuration changes, allowing the DevOps team to track and monitor changes across the application stack.
