#Q
*Acme Corporation, a leading technology company in the e-commerce industry, is aiming to enhance its application's cost efficiency and scalability by implementing a serverless architecture. To accomplish this goal, Acme Corporation seeks guidance on selecting the most suitable AWS service for their specific requirements.*
1. Amazon RDS    
2. AWS Lambda    
3. Amazon EC2    
4. Amazon S3
?
**Answer:**
[[AWS Lambda]]

**Explanation:**
AWS Lambda is a serverless computing service that allows developers to run code without provisioning or managing servers, making it a cost-effective and scalable solution for applications.
