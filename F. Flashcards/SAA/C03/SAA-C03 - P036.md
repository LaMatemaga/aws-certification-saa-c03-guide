#Q
*You need to create a solution that allows your EC2 instances to retrieve application secrets securely. What service do you recommend for storing and retrieving the secrets?*
1. AWS Systems Manager Parameter Store
2. AWS Identity and Access Management
3. AWS Secrets Manager
4. AWS Key Management Service
?
**Answer:**
[[AWS Secrets Manager]]

**Explanation:**
AWS Secrets Manager is specifically designed for storing and managing secrets, like database credentials or API keys. This service would be best suited for securely retrieving application secrets.
