#Q
*A company is designing a new application that will store and retrieve millions of small files. The application needs to be able to quickly read and write these files. Which AWS service should be used? (One option)*
1. Amazon EFS
2. Amazon Glacier
3. Amazon DynamoDB
4. Amazon S3
?
**Answer:**
[[Amazon Elastic File System (Amazon EFS)]]

**Explanation:**
Amazon EFS provides a simple, scalable, and fully managed elastic NFS file system for use with AWS Cloud services and on-premises resources.
