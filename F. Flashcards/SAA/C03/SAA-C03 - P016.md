#Q
*You have to design an architecture to host a web application that is expected to have unpredictable traffic patterns. Which EC2 pricing option is most cost-effective in this scenario? (One option)*
1. Reserved Instances
2. Dedicated Instances
3. Spot Instances
4. On-Demand Instances
?
**Answer:**
[[Spot Instance]]s

**Explanation:**
Spot Instances offer spare AWS compute capacity at up to 90% off the On-Demand price, and are well suited for applications with flexible start and end times, or that are feasible at very low compute prices.
