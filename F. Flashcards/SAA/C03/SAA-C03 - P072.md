#Q
*A company wants to ensure that its web application can handle sudden traffic spikes without impacting performance. Which AWS service provides an elastic and scalable solution for this scenario?*
1. Amazon S3
2. Amazon EC2 Auto Scaling
3. Amazon CloudFront
4. AWS Lambda
?
**Answer:**
[[Amazon EC2 Auto Scaling]]

**Explanation:**
Amazon EC2 Auto Scaling allows for automatic scaling of EC2 instances based on traffic demand, ensuring that the application can handle sudden traffic spikes without impacting performance.
