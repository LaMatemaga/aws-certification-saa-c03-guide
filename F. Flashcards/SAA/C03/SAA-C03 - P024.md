#Q
*A company is planning to migrate its existing on-premises application to AWS. The application consists of multiple components that communicate with each other using TCP/IP. The company wants to ensure secure communication between these components while minimizing the administrative overhead. Which AWS service should be used to meet these requirements? (One option)*
1. AWS PrivateLink
2. AWS Direct Connect
3. AWS VPN
4. AWS Transit Gateway
?
**Answer:**
[[AWS PrivateLink]]

**Explanation:**
AWS PrivateLink allows you to securely access services hosted on AWS privately, without using public IPs, NAT devices, or VPN connections. It enables you to establish private connectivity between VPCs, VPCs and AWS services, or between your on-premises network and AWS services. In this scenario, AWS PrivateLink can be used to establish secure and low-latency communication between the components of the application, minimizing administrative overhead.
