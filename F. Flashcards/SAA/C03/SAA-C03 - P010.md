#Q
*In an effort to optimize costs, you're asked to select the most cost-effective storage solution for infrequently accessed data. Which service would you recommend? (One option)*
1. Amazon EFS
2. Amazon S3 Glacier
3. Amazon S3 Standard
4. Amazon EBS
?
**Answer:**
[[Amazon S3 Glacier]]

**Explanation:**
Amazon S3 Glacier is a storage service optimized for infrequently accessed data and is the most cost-effective option for such data.
