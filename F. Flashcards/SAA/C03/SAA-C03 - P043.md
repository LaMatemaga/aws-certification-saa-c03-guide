#Q
*Your company is looking to ensure high resilience and availability for a critical application hosted on EC2. Which of the following methods would be most effective in achieving this?*
1. Deploy the application across multiple regions.
2. Deploy the application in one availability zone and have a backup in another.
3. Deploy the application across multiple availability zones within the same region
4. Keep the application in one availability zone and use Auto Scaling.
?
**Answer:**
Deploy the application across multiple [[Availability Zone (AZ)]]s within the same [[region]]

**Explanation:**
Deploying the application across multiple Availability Zones in the same region provides the best [[resilience]] and [[availability]].
