#Q #AOSR/18lgu
*You are tasked with designing a highly scalable and high-performing architecture for a stateless web application. Which AWS services should be included in the design? (Multiple option)*
1. Amazon EC2
2. Amazon S3
3. Amazon RDS
4. Amazon Redshift
5. AWS Lambda
? #AOSR/18lgu/m/so01
**Answer:**
[[AWS Lambda]] and [[Amazon S3]]

**Explanation:**
AWS Lambda can be used to run the application code without provisioning servers, and Amazon S3 can be used to serve static web content, both contributing to scalability and performance.
