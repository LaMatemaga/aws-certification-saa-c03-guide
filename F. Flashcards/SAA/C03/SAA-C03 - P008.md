#Q
*As a solutions architect, what measures can be taken to enhance application performance when a developer identifies prolonged query execution time on the database? How can common queries be stored and performance be optimized? (One option)*
1. Simple Queue Service (SQS)
2. Elastic Block Store (EBS)
3. ElastiCache
4. CloudFront 
?
**Answer:**
[[Amazon ElastiCache]]

**Explanation:**
ElastiCache is a managed in-memory caching service provided by AWS. By storing commonly used queries in an in-memory cache, ElastiCache reduces the need for querying the database repeatedly, resulting in improved performance and reduced latency. It is specifically designed to enhance the performance of read-heavy workloads by providing low-latency data access. Therefore, ElastiCache is the most suitable solution to store common queries and improve application performance in this scenario.
