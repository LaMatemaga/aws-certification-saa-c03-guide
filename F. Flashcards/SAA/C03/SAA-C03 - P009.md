#Q
*You need to design a solution that will allow a company to migrate its on-premises data center to AWS. The solution should provide low-latency, high-throughput connectivity. Which AWS service should be used? (One option)*
1. Amazon S3 Transfer Acceleration
2. AWS VPN
3. AWS Snowball
4. AWS Direct Connect
?
**Answer:**
[[AWS Direct Connect]]

**Explanation:**
AWS Direct Connect provides a dedicated network connection from your premises to AWS.
