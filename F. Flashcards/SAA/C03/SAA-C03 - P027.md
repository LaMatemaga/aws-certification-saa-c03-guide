#Q
*A web application is deployed in the AWS Cloud. It consists of a two-tier architecture that includes a web layer and a database layer. The web server is vulnerable to cross-site scripting (XSS) attacks. What should a solutions architect do to remediate the vulnerability?*
1. Create a Classic Load Balancer. Put the web layer behind the load balancer and enable AWS WAF.
2. Create an Application Load Balancer. Put the web layer behind the load balancer and enable AWS WAF. 
3. Create a Network Load Balancer. Put the web layer behind the load balancer and enable AWS WAF. 
4. Create an Application Load Balancer. Put the web layer behind the load balancer and use AWS Shield Standard.
?
**Answer:**
Create an Application Load Balancer. Put the web layer behind the load balancer and enable [[AWS WAF]].

**Explanation:**
To mitigate the XSS vulnerability, an Application Load Balancer (ALB) should be created and the web layer should be placed behind it. ALB provides Layer 7 load balancing, allowing it to inspect and forward traffic at the application layer. By enabling AWS Web Application Firewall (WAF) on the ALB, you can protect the web server from common web exploits, including XSS attacks.
