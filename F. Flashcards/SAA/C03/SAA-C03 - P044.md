#Q
*An application needs to retrieve sensitive data from an S3 bucket. Which of the following provides the most secure way to access the data?*
1. Enabling public read access on the S3 bucket
2. Allowing all inbound traffic on the security group associated with the EC2 instance
3. Storing the AWS Access Key and Secret Key in the application code
4. Using an IAM role for EC2 instances
?
**Answer:**
Using an IAM role for [[Amazon EC2]] instances

**Explanation:**
IAM roles provide a secure way to delegate permissions to resources that AWS services will use.
