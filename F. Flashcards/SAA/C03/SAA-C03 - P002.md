#Q #AOSR/3tg9r
*A company is running a highly sensitive application on Amazon EC2 backed by an Amazon RDS database. Compliance regulations mandate that all personally identifiable information (PII) be encrypted at rest. Which solution should a solutions architect recommend to meet this requirement with the LEAST amount of changes to the infrastructure? (One option)*
1. Configure Amazon Elastic Block Store (Amazon EBS) encryption and Amazon RDS encryption with AWS Key Management Service (AWS KMS) keys to encrypt instance and database volumes.
2. Deploy AWS Certificate Manager to generate certificates. Use the certificates to encrypt the database volume.
3. Configure SSL encryption using AWS Key Management Service customer master keys (AWS KMS CMKS) to encrypt database volumes.
4. Deploy AWS Cloud HSM, generate encryption keys, and use the customer master key (CMK) to encrypt database volumes.
? #AOSR/3tg9r/m/5iuh
**Answer:**
Configure [[Amazon Elastic Block Store (Amazon EBS)]] encryption and [[Amazon RDS]] encryption with [[AWS Key Management Service (AWS KMS)]] keys to encrypt instance and database volumes.

**Explanation:**  
Amazon Elastic Block Store (Amazon EBS) encryption allows you to encrypt the storage volumes attached to [[Amazon EC2]] instances. By enabling EBS encryption, you can ensure that the data at rest on the EC2 instance's volumes is encrypted. This will protect the sensitive application's data.
