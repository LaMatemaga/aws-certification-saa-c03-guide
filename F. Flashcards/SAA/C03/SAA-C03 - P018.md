#Q
*A company wants to design a highly available and scalable architecture for its data analytics platform on AWS. The platform requires near real-time processing of large data sets and needs to support both batch processing and stream processing. Which AWS service should be used to meet these requirements? (One option)*
1. Amazon Redshift
2. Amazon Athena
3. Amazon EMR
4. AWS Glue
?
**Answer:**
[[Amazon EMR]]

**Explanation:**
Amazon EMR (Elastic MapReduce) is a fully managed big data processing service that supports both batch processing and stream processing. EMR uses Apache Hadoop, Apache Spark, and other open-source frameworks to process large data sets in near real-time. It provides scalability, fault tolerance, and cost optimization for data analytics workloads.
