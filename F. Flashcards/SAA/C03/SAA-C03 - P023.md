#Q
*A solutions architect is tasked with ensuring secure access to an Amazon RDS database. Which of the following will ensure secure connections to the RDS instance? (One option)*
1. Assign an IAM role to the RDS instance
2. Force SSL connections to the RDS instance
3. Configure RDS to only accept connections over HTTPS.
4. Use RDS in a VPC and enable VPC peering
?
**Answer:**
Force SSL connections to the [[Amazon RDS]] instance

**Explanation:**
Forcing SSL connections will ensure that all connections to the RDS instance are encrypted and thus secure.
