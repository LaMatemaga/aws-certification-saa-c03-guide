#Q
*Which load balancer would be the most suitable choice for balancing both HTTP and HTTPS traffic in the newly developed app?*
1. Network Load Balancer
2. Classic Load Balancer
3. Application Load Balancer
4. HTTP Load Balancer
?
**Answer:**
Application Load Balancer

**Explanation:**
The Application Load Balancer is the best choice for balancing both HTTP and HTTPS traffic in an application. It operates at the application layer (Layer 7) of the OSI model and can distribute traffic based on various criteria, including URL path, hostname, or query string. It supports both HTTP and HTTPS protocols, allowing it to handle secure traffic while also providing advanced features such as content-based routing, SSL offloading, and sticky sessions. This makes it the most suitable load balancer option for applications that require the balancing of both HTTP and HTTPS traffic.
