#Q
*A global media company uses a fleet of EC2 instances (behind an Application Load Balancer) to power its video streaming application. To improve the performance of the application, the engineering team has also created a CloudFront distribution with the Application Load Balancer as the custom origin. The security team at the company has noticed a spike in the number and types of SQL injection and cross-site scripting attack vectors on the application. As a solutions architect, which of the following solutions would you recommend as the MOST effective in countering these malicious attacks?*
1. Use Route 53 with CloudFront distribution
2. Use Security Hub with CloudFront distribution
3. Use AWS Firewall Manager with CloudFront distribution
4. Use Web Application Firewall (WAF) with CloudFront distribution
?
**Answer:**
Use Web Application Firewall ([[AWS WAF]]) with [[Amazon CloudFront]] distribution

**Explanation:**
Web Application Firewall (WAF) is specifically designed to protect web applications from common attack vectors, such as SQL injection and cross-site scripting. It acts as a shield between the application and the internet, inspecting and filtering the traffic to identify and block malicious requests.
