#Q
*A company wants to ensure that data transferred between EC2 instances within its VPC remains secure. Which of the following options will encrypt the data in transit? (Select two)*
1. Enable SSL/TLS encryption on the EC2 instances
2. Use AWS PrivateLink to establish a private network connection between the EC2 instances
3. Use an Internet Gateway to route the traffic between the EC2 instances
4. Enable AWS Shield Advanced to protect the EC2 instances from DDoS attacks
5. Configure a VPC peering connection between the EC2 instances.
?
**Answer:**
6. Enable SSL/TLS encryption on the [[Amazon EC2]] instances
7. Use [[AWS PrivateLink]] to establish a private network connection between the EC2 instances
**Explanation:**
