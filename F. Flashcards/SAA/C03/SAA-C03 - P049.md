#Q
*A freelance developer has built a Python based web application. The developer would like to upload his code to AWS Cloud and have AWS handle the deployment automatically. He also wants access to the underlying operating system for further enhancements. As a solutions architect, which of the following AWS services would you recommend for this use-case?*
1. Amazon EC2
2. AWS Elastic Beanstalk
3. AWS CloudFormation
4. AWS Elastic Container Service (ECS)
?
**Answer:**
[[AWS Elastic Beanstalk]]

**Explanation:**
AWS Elastic Beanstalk is the correct answer because it provides automatic deployment and management of web applications on AWS. It supports various programming languages, including Python, and offers access to the underlying infrastructure for further customization.
