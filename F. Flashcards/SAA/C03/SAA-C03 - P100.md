#Q
*A solutions architect needs to design a solution for a web application that will be hosted in a public subnet and will connect to a database in a private subnet. The database should not be accessible from the internet. What should the architect use to allow the application to connect to the database?*
1. VPC Endpoints
2. VPC Peering
3. Internet Gateway
4. NAT Gateway
?
**Answer:**
VPC Endpoints

**Explanation:**
VPC Endpoints allow private connectivity between your VPC and supported AWS services without requiring access over the Internet.
