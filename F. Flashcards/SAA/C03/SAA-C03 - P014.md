#Q
*A Machine Learning research group uses a proprietary computer vision application hosted on an EC2 instance. Every time the instance needs to be stopped and started again, the application takes about 3 minutes to start as some auxiliary software programs need to be executed so that the application can function. The research group would like to minimize the application boostrap time whenever the system needs to be stopped and then started at a later point in time. As a solutions architect, which of the following solutions would you recommend for this use-case? (One option)*
1. Create an AMI and launch your EC2 instances from that
2. Use EC2 Meta-Data
3. Use EC2 Instance Hibernate
4. Use EC2 User-Data
?
**Answer:**
Use EC2 Instance Hibernate

**Explanation:**
This is the best choice given the use-case. When an EC2 instance is put into hibernation, it saves the in-memory state of the instance, including the applications running on it. When the instance is restarted, it returns to its pre-hibernation state much more quickly than a regular start-up process. This would eliminate the need to re-run the auxiliary software programs every time the instance is started, thus minimizing bootstrap time.
