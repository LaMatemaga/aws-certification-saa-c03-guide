#Q
*The development of a new mobile app requires the implementation of effective traffic filtering to safeguard the Application Load Balancer (ALB) against prevalent application-level attacks, like cross-site scripting and SQL injection. With limited infrastructure and operational personnel, the company aims to decrease its burden in terms of server management, updates, and security for its AWS environment. What should a solutions architect recommend to meet these requirements?*
1. Create a new ALB that directs traffic to an Amazon EC2 instance running a third-party firewall, which then passes the traffic to the current ALB
2. Configure AWS WAF rules and associate them with the ALB
3. Deploy AWS Shield Advanced and add the ALB as a protected resource
4. Deploy the application using Amazon S3 with public hosting enabled
?
**Answer:**
Configure [[AWS WAF]] rules and associate them with the ALB

**Explanation:**
Configuring AWS WAF rules and associating them with the ALB allows for effective traffic filtering to safeguard against prevalent application-level attacks like cross-site scripting and SQL injection. AWS WAF provides a web application firewall that can inspect and filter traffic based on predefined rulesets or custom rules. By configuring these rules and associating them with the ALB, the company can protect their application from malicious traffic without the need for additional infrastructure or operational personnel. This solution decreases the burden of server management, updates, and security for the AWS environment.
