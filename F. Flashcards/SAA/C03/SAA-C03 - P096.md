#Q
*You are designing an application that will store highly sensitive user data. Which AWS service will provide a hardware security module to store cryptographic keys?*
1. AWS Shield
2. AWS WAF
3. AWS KMS
4. AWS CloudHSM
?
**Answer:**
[[AWS CloudHSM]]

**Explanation:**
AWS CloudHSM is a cloud-based hardware security module (HSM) that enables you to generate and use your own encryption keys on the AWS Cloud.
