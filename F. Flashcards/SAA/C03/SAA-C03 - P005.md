#Q
*A company is building a new application on AWS that requires secure and durable storage to hold encrypted user passwords. Which service should be used to store the passwords? (One option)*
1. AWS Key Management Service (KMS)
2. AWS Secrets Manager
3. Amazon Simple Storage Service (S3)
4. Amazon DynamoDB
?
**Answer:**
[[AWS Secrets Manager]]

**Explanation:**
AWS Secrets Manager is designed for storing, retrieving, and rotating secrets like database credentials or API keys. It’s the best fit for securely storing user passwords.
