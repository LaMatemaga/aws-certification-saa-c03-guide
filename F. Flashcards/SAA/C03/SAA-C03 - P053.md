#Q
*A recently acquired company is required to build its own infrastructure on AWS and migrate multiple applications to the cloud within a month. Each application has approximately 50 TB of data to be transferred. After the migration is complete, this company and its parent company will both require secure network connectivity with consistent throughput from their data centers to the applications. A solutions architect must ensure one-time data migration and ongoing network connectivity. Which solution will meet these requirements?*
1. AWS Direct Connect for both the initial transfer and ongoing connectivity
2. AWS Snowball for the initial transfer and AWS Site-to-Site VPN for ongoing connectivity
3. AWS Snowball for the initial transfer and AWS Site-to-Site VPN for ongoing connectivity
4. AWS Snowball for the initial transfer and AWS Direct Connect for ongoing connectivity
?
**Answer:**
[[AWS Snowball]] for the initial transfer and [[AWS Direct Connect]] for ongoing connectivity

**Explanation:**
AWS Snowball is a physical data transport solution that allows for secure and efficient transfer of large amounts of data to and from AWS. Since each application has approximately 50 TB of data, Snowball can be used to expedite the initial transfer by shipping the data on a Snowball device directly to AWS data centers. This avoids the limitations and potential network congestion associated with transferring such large volumes of data over the internet.
