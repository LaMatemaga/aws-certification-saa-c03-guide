#Q
*A company hosts a static website within an Amazon S3 bucket. A solutions architect needs to ensure that data can be recovered in case of accidental deletion. Which action will accomplish this? (One option)*
1. Enable Amazon S3 cross-Region replication
2. Enable Amazon S3 versioning
3. Enable an Amazon S3 lifecycle policy
4. Enable Amazon S3 Intelligent-Tiering
?
**Answer:**
Enable Amazon S3 versioning

**Explanation:**
Enabling Amazon S3 versioning ensures that multiple versions of an object (file) are stored within the S3 bucket. This allows you to recover previous versions of the object in case of accidental deletion or modification. When versioning is enabled, every time a new version of an object is uploaded, it is stored as a separate version, maintaining a history of changes.

By enabling versioning, you can easily restore a previous version of a file if it gets deleted or overwritten by mistake. It provides an added layer of protection and allows for easy recovery of data.
