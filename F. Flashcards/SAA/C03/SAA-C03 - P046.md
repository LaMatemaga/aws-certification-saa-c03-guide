#Q
*A business entity has a crucial requirement to enhance the security related to the access of its Amazon RDS database. They have a stipulation in place which mandates that only certain, predetermined IP addresses should be given the permission to establish a connection to the database. The question that arises now is - what needs to be configured, modified or implemented to cater to these stringent security needs?*
1. by using Could Network Access Control Lists (ACLs) to act as a firewall for associated subnets, controlling inbound and outbound traffic
2. VPC Peering, which allows you to connect one VPC with another via a direct network route using private IP addresses
3. Use Security groups to act as a virtual firewall for associated Amazon EC2 instances, controlling inbound and outbound traffic
?
**Answer:**
Use Security groups to act as a virtual firewall for associated [[Amazon EC2]] instances, controlling inbound and outbound traffic

**Explanation:**
Security groups can be configured to control inbound and outbound traffic for Amazon RDS instances. By specifying the specific IP addresses in the security group rules, the company can allow only those addresses to connect to the database. Security groups act as virtual firewalls that filter traffic based on the rules defined, providing secure access control to the database.
