#Q
*A company wants to design a cost-optimized architecture for its web application. The application consists of multiple EC2 instances behind an Application Load Balancer (ALB). The traffic pattern is highly variable, with peak traffic occurring only for a few hours each day. Which EC2 instance purchasing option should be used to minimize costs?*
1. Reserved Instances
2. On-Demand Instances
3. Dedicated Hosts
4. Spot Instances
?
**Answer:**
[[Spot instance]]s

**Explanation:**
Spot Instances allow you to take advantage of spare EC2 capacity at significantly lower costs compared to On-Demand or Reserved Instances. They are ideal for workloads with flexible start and end times, such as peak traffic periods, as you can bid for the instance capacity based on your price. However, Spot Instances can be terminated if the spot price exceeds your bid or if the capacity becomes limited, so they may not be suitable for applications with strict availability requirements.
