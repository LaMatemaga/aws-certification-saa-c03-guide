#Q
*The company is seeking to create a data processing architecture on AWS that is both scalable and cost-effective. Their goal is to efficiently handle substantial amounts of data with minimal delay while also minimizing expenses by processing data solely when necessary. Given these requirements, which AWS service would be most suitable to fulfill their needs?*
1. AWS Glue
2. Amazon Kinesis
3. AWS Lambda
4. AWS Step Functions
?
**Answer:**
[[Amazon Kinesis]]

**Explanation:**
Amazon Kinesis is a fully managed service for real-time streaming data processing. It can process and analyze large volumes of data with low latency. With Kinesis, the company can ingest, process, and store streaming data to enable real-time analytics, insights, and actions. By using Kinesis, the company can minimize costs by processing data only when needed, providing a scalable and cost-effective data processing architecture
