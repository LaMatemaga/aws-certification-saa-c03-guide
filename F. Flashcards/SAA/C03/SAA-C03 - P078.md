#Q
*A company wants to design a highly available and scalable architecture for its web application. The application needs to handle sudden traffic spikes and must maintain session affinity. Which AWS service should be used to meet these requirements?*
1. Amazon CloudFront
2. Elastic Load Balancing (ELB)
3. Amazon ElastiCache
4. AWS Lambda 
?
**Answer:**
[[Elastic Load Balancing (ELB)]]

**Explanation:**
Elastic Load Balancing (ELB) automatically distributes incoming application traffic across multiple targets, such as EC2 instances, containers, and IP addresses, to improve availability and fault tolerance of the application. ELB supports session affinity, allowing you to maintain session stickiness for clients. By using ELB, the application can handle sudden traffic spikes, scale resources accordingly, and maintain session affinity for a seamless user experience.
