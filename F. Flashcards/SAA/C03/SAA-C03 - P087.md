#Q
*A sports data company is delivering real-time data to media companies, sports federations, and the betting industry using its IT infrastructure on AWS Cloud. The company wants an urgent solution that provides a low-latency way to ingest live sports results regardless of where in the world their sports journalists are sitting. The live sports results are delivered via a proprietary application using UDP protocol. As a solutions architect, which of the following solutions would you recommend such that it offers the BEST performance for ingesting live sports results?*
1. Use Global Accelerator to provide a low latency way to ingest live sports results
2. Use CloudFront to provide a low latency way to ingest live sports results
3. Use Auto Scaling group to provide a low latency way to ingest live sports results
4. Use Elastic Load Balancer to provide a low latency way to ingest live sports results
?
**Answer:**
Use [[AWS Global Accelerator]] to provide a low latency way to ingest live sports results

**Explanation:**
Global Accelerator is specifically designed to provide low-latency and high-performance network connectivity by leveraging the AWS global network infrastructure, making it ideal for ingesting live sports results from journalists located worldwide.
