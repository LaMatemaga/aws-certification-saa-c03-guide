#Q
*A company is seeking to establish secure access to Amazon Elastic Compute Cloud (EC2) instances that are currently operating within a Virtual Private Cloud (VPC). Among the following options, which two can be employed to achieve secure access? (Select two)*
1. Enable Security Group rule to allow SSH traffic from 0.0.0.0/0
2. Enable password-based authentication for SSH access
3. Configure security groups to allow inbound SSH traffic from the company's IP range
4. Use AWS Systems Manager Session Manager for SSH access
5. Use a bastion host with a limited set of IP addresses allowed for SSH access
?
**Answer:**
6. Configure security groups to allow inbound SSH traffic from the company's IP range
7. Use a bastion host with a limited set of IP addresses allowed for SSH access

**Explanation:**
Configuring security groups to allow inbound SSH traffic from specific IP ranges and using a bastion host with limited IP addresses provide secure access to EC2 instances
