#Q
*A social media startup uses AWS Cloud to manage its IT infrastructure. The engineering team at the startup wants to perform weekly database rollovers for a MySQL database server using a serverless cron job that typically takes about 5 minutes to execute the database rollover script written in Python. The database rollover will archive the past week's data from the production database to keep the database small while still keeping its data accessible. As a solutions architect, which of the following would you recommend as the MOST cost- efficient and reliable solution?*
1. Provision an EC2 scheduled reserved instance to run the database rollover script to be run via an OS-based weekly cron expression
2. Provision an EC2 spot instance to run the database rollover job triggered via an OS-based weekly cron expression
3. Schedule a weekly CloudWatch event cron expression to invoke a Lambda function that runs the database rollover job
4. Create a time-based schedule option within an AWS Glue job to invoke itself every week and run the database rollover script
?
**Answer:**
Schedule a weekly CloudWatch event cron expression to invoke a Lambda function that runs the database rollover job

**Explanation:**
By scheduling a weekly CloudWatch event to trigger a Lambda function, which runs the database rollover job. This solution is cost-efficient as it only incurs costs during the execution time of the Lambda function, and it is reliable as AWS manages the underlying infrastructure for Lambda, ensuring high availability and scalability.
