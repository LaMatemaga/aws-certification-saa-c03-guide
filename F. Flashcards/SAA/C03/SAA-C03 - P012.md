#Q
*A company wants to design a data backup and restore solution on AWS for its business-critical application. The company requires automated backups, point-in-time recovery, and long-term data retention. Which AWS service should be used to meet these requirements? (One option)*
1. Amazon S3
2. AWS Backup
3. AWS Storage Gateway
4. AWS Snowball
?
**Answer:**
[[AWS Backup]]

**Explanation:**
AWS Backup is a fully managed backup service that centralizes and automates the backup of data across AWS services. It supports automated backups, point-in-time recovery, and long-term data retention. With AWS Backup, the company can create backup plans, set backup schedules, and manage backup policies for its business-critical application, ensuring data durability, availability, and recoverability.
