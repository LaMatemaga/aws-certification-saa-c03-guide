#Q
*You are designing a resilient architecture for a critical two-tier web application. The application includes a web tier running on EC2 instances and a MySQL database. The application must be available at all times. Which solution would offer the highest availability?*
1. Use a single-AZ RDS MySQL instance for the database
2. Use an EC2 instance for the database and enable cross-region replication
3. Use an EC2 instance for the database and create snapshots every 5 minutes
4. Use a Multi-AZ RDS MySQL deployment for the database
?
**Answer:**
Use a Multi-AZ RDS MySQL deployment for the database

**Explanation:**
A Multi-AZ RDS MySQL deployment automatically implements a primary/standby replication in different Availability Zones to ensure high availability and automatic failover.
