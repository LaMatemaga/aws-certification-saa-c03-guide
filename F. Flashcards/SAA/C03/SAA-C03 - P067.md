#Q
*A company wants to design a secure architecture for its web application on AWS. The application will store sensitive customer data, and strict access controls need to be enforced. Which AWS service can be used to centrally manage access to AWS resources and implement fine-grained permissions?*
1. AWS CloudTrail
2. AWS Identity and Access Management (IAM)
3. AWS Key Management Service (KMS)
4. AWS Certificate Manager
?
**Answer:**
[[AWS Identity and Access Management (IAM)]]

**Explanation:**
AWS Identity and Access Management (IAM) allows you to centrally manage access to AWS resources. It provides fine-grained access control using policies and permissions, enabling you to enforce strict access controls for sensitive customer data. IAM enables you to create and manage users, groups, and roles with specific permissions, ensuring secure access to AWS resources.
