#Q
*A company has several EC2 instances and employees access them over the internet using Public IP address. When instances are stopped and started, employees are complaining that they are not able to connect. What option would you recommend?*
1. Public IP address does not change when instance is stopped and started. Most likely instance was terminated and relaunched
2. Use Bastian Host with an Elastic IP Address. Ask employees to first connect to Bastian Host and then login to their instance using private IP address
3. Instead of public IP address, use Elastic IP address for the instances. This will ensure IP address remains the same for the instances between stop and start cycles
4. Configure EC2 settings to assign same Public IP Address when instance is stopped and started
?
**Answer:**
Use Bastian Host with an Elastic IP Address. Ask employees to first connect to Bastian Host and then login to their instance using private IP address

**Explanation:**
Using a Bastion Host with an Elastic IP Address allows employees to connect to the instances using a private IP address. This ensures that even if the public IP address of the instances changes when they are stopped and started, employees can still access them through the Bastion Host with a consistent and static Elastic IP Address.
