#Q
*You have multiple AWS accounts, and you want to centrally manage IAM users and groups across all of these accounts. What AWS service will you use to achieve this?*
1. AWS Directory Service
2. AWS Single Sign-On
3. AWS IAM
4. AWS Organizations
?
**Answer:**
[[AWS Organizations]]

**Explanation:**
AWS Organizations allows you to centrally manage and govern your environment as you grow and scale your AWS resources
