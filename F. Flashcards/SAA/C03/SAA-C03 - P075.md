#Q
*You have a serverless application composed of API Gateway, Lambda, and DynamoDB. During peak usage, users report timeouts. After investigating, you find that the issue lies with DynamoDB throttling requests. What should you do to solve this issue?*
1. All of these options
2. Increase the read and write capacity units of the DynamoDB table
3. Increase the memory allocation to the Lambda function
4. Use an ElastiCache layer to cache the most commonly accessed data
?
**Answer:**
Increase the read and write capacity units of the [[Amazon DynamoDB]] table
 
**Explanation:**
Increasing the read and write capacity of the DynamoDB table should solve the problem if it is due to DynamoDB throttling requests.
