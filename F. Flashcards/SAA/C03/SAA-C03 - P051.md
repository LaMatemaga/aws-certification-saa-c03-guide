#Q
*In order to meet the company's requirements of ensuring data durability and availability for its Amazon S3 objects, the appropriate storage class to consider would be the one that provides redundancy across multiple facilities. Which storage class in Amazon S3 should be selected to fulfill these specific needs?*

1. Glacier
2. One Zone-IA
3. S3 Intelligent-Tiering
4. Standard-IA (Infrequent Access) 
?
**Answer:**
Standard-IA (Infrequent Access)

**Explanation:**
The Standard-IA (Infrequent Access) storage class in [[Amazon S3]] provides durability and availability for objects by storing them redundantly across multiple facilities. Standard-IA is designed for objects accessed less frequently but still requires high durability and availability. It offers a lower storage cost compared to the Standard storage class while ensuring data redundancy across multiple facilities.
