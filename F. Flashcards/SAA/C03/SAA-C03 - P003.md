#Q
*An organization is planning to use AWS for their production environment. The company requires that their data always remain in a specific AWS region due to data sovereignty requirements. How can they ensure compliance? (One option)*
1. Use Direct Connect to keep data in a particular region
2. Set a data residency policy in AWS IAM
3. Use AWS Resource Access Manager to keep data in a specific region
4. Use Placement Groups to keep data in a specific region
?
**Answer:**
Set a data residency policy in AWS IAM
 
**Explanation:**
While AWS does not move data between regions unless explicitly directed by the user, there is no IAM policy related to data residency. Users can control where data is stored by choosing the region in which to store and process it.
