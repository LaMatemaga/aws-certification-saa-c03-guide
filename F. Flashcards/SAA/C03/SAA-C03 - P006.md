#Q
*The company has a specific need to ensure the secure encryption of data that is stored in an Amazon S3 bucket. In order to meet this requirement, they are seeking information on the encryption options that should be taken into consideration. You are asked to select an encryption options from the available choices. (One option)*
1. Server-side encryption with Amazon S3 managed keys
2. Client-side encryption using AWS Certificate Manager
3. Client-side encryption using AWS CloudHSM
4. Server-side encryption with customer-provided keys (SSE-C)
?
**Answer:**
Server-side encryption with [[Amazon S3]] managed keys

**Explanation:**
Server-side encryption with Amazon S3 managed keys (SSE-S3) provide options to securely encrypt data at rest in an S3 bucket.
