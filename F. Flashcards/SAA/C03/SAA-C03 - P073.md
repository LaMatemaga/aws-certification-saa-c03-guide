#Q
*The company is seeking to develop a robust architecture for its web application that operates on Amazon EC2 instances. To achieve high availability, what are the essential features that should be taken into account? Please select three from the following options.*
1. Utilize multiple Availability Zones within a single AWS Region
2. Implement Elastic Load Balancing to distribute traffic across instances
3. Configure Amazon RDS Multi-AZ for database resilience
4. Use Auto Scaling to automatically add or remove instances based on demand
5. Deploy the application in multiple AWS Regions
?
**Answer:**
6. Utilize multiple [[Availability Zone]]s within a single AWS Region
7. Implement [[Elastic Load Balancing (ELB)]] to distribute traffic across instances
8. Use [[AWS Auto Scaling]] to automatically add or remove instances based on demand

**Explanation:**
Auto Scaling ensures that the application can handle varying levels of traffic. Multiple Availability Zones provide redundancy and fault tolerance, while Elastic Load Balancing distributes traffic across instances for load balancing.
