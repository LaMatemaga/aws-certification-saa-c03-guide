#Q
*The company has set up an EC2 instance as a web server within a subnet in a VPC. However, the web application running on the server is currently unable to access the internet. Which component is likely missing?*
1. Peering connection
2. Internet gateway
3. Network Access Control List (NACL)
4. Private IP address for the instance
?
**Answer:**
Internet gateway

**Explanation:**
An internet gateway acts as a bridge between a VPC and the internet. It allows traffic to flow between the VPC and the internet, enabling internet connectivity for resources within the VPC. In this scenario, since the web application on the EC2 instance is unable to access the internet, it suggests that an internet gateway has not been properly configured or attached to the VPC.
