#Q
*A company wants to deploy a highly scalable storage solution on AWS. The solution should automatically scale storage capacity as data grows without any performance impact. Which AWS service should be used to meet these requirements?*
1. Amazon S3
2. Amazon EBS
3. Amazon RDS
4. Amazon EFS
?
**Answer:**
[[Amazon S3]]

**Explanation:**
Amazon S3 (Simple Storage Service) is a scalable object storage service that provides unlimited storage capacity. It can automatically scale to accommodate data growth without any performance impact. Amazon S3 is designed for durability, availability, and scalability, making it an ideal choice for highly scalable storage solutions.
