#Q
*A company wants to design a highly available and fault-tolerant architecture for its web application running on AWS. The application consists of multiple EC2 instances behind an Application Load Balancer (ALB) and an Amazon RDS database. Which AWS service should be used to ensure automatic recovery of failed EC2 instances?*
1. AWS Elastic Load Balancing
2. AWS Elastic Beanstalk
3. AWS Lambda
4. AWS Auto Scaling
?
**Answer:**
[[AWS Auto Scaling]]

**Explanation:**
AWS Auto Scaling allows you to automatically adjust the number of EC2 instances based on demand. It can help maintain application availability by automatically recovering failed instances and replacing them with new ones. By configuring scaling policies, you can ensure that the desired number of instances is always running, providing a highly available and fault-tolerant architecture.
