#Q
*A company wants to analyze the data residing in their on-premises SQL Server and Oracle databases using Amazon Redshift. What is the most efficient method to accomplish this?*
1. Using Amazon Kinesis Data Firehose to stream the data to Redshift
2. Using AWS Data Migration Service to replicate the data to Redshift
3. Manually exporting the data and importing it into Redshift
4. Using Amazon RDS to replicate the data to Redshift
?
**Answer:**
Using AWS Data Migration Service to replicate the data to Redshift

**Explanation:**
AWS DMS (Data Migration Service) supports both homogeneous and heterogeneous migrations and can help migrate data from on-premises databases to Redshift efficiently.
