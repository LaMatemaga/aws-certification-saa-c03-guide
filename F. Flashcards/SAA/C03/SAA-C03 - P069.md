#Q
*The company seeks to transfer its on-premises database to AWS, emphasizing minimal downtime. They are in search of an AWS service that enables a live migration process without significant interruptions. Which AWS service provides a reliable solution for a seamless live migration, ensuring minimal disruption to operations?*
1. By using AWS DataSync
2. By using Database Migration Service (DMS)
3. By using AWS Server Migration Service (SMS)
4. By using AWS Snowball
?
**Answer:**
By using [[AWS Database Migration Service (AWS DMS)]]

**Explanation:**
AWS Database Migration Service (DMS) can be used to migrate an existing database to AWS with minimal downtime. DMS supports live migrations, allowing the source database to remain operational during the migration process. DMS continuously replicates data changes from the source to the target database until the final cutover, minimizing downtime and ensuring a smooth transition.
