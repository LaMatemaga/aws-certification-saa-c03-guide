#Q
*You are designing a high-performing architecture for a big data application. The application needs to process a vast amount of data quickly. Which of the following services should you use?*
1. Amazon RDS
2. Amazon EMR
3. Amazon EC2
4. AWS Glue
?
**Answer:**
[[Amazon EMR]]

**Explanation:**
Amazon EMR provides a managed Hadoop framework that simplifies the processing of large amounts of data across dynamically scalable Amazon EC2 instances.
